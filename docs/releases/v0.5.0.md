# HoudiniRT 0.5.0 — integrated UVs, textures and HDRI lighting

This public preview brings the tested native renderer and Houdini artist controls
into one Windows x64 bundle for **Houdini 22.0.429**. Materials and lights are
authored in native Solaris nodes; one HoudiniRT panel controls the intended viewer.

## What artists can use

- Indexed `st` UVs, including face-varying seams, and native Texcoord/Geompropvalue,
  Place2D and USD Transform2D coordinates.
- MaterialX Image inputs for OpenPBR base color, base weight, metalness, specular
  color, specular weight, roughness and IOR. PNG/JPEG/EXR/HDR decoding and active
  Houdini OCIO conversion; scalar maps remain data.
- Closest/bilinear filtering with constant, clamp, periodic and mirror addressing.
- Up to eight latitude-longitude HDRI Dome Lights with native pole-axis, rotation,
  exposure and tint controls, including importance sampling and MIS.
- Existing live scene updates, GPU accumulation/resolve, authored normals,
  distant/rectangle/disk/sphere lighting and geometric diagnostic outputs.
- Integrated Enable, actual renderer/pause readback, Pause/Resume, latest-scene
  updates after paused edits, and restoration of the previous renderer and grids.

Download the ZIP and `SHA256SUMS` below. Follow the included README; copy its
package JSON and versioned payload together into Houdini's preferences packages
folder. Renderer and controls are included; no assistant runtime is required.
The GitHub-generated source archives are source code, not an installed plugin.

## Verified scope

The shipped DLL, shader bytecode and Python runtime files match the locally
installed and tested Phase 4B build, code commit
`87bff34e87d242d59a30fd6f222e625445a66976`. Packaging adds portable registration,
current instructions, license texts and a manifest; it does not rebuild the renderer.

- Nine live regular-Houdini images exactly matched fresh process/delegate captures
  in full RGBA. All native UV/map/HDRI edits changed pixels; baseline restoration
  was exact. Viewer isolation and previous paused Karma/grid restoration passed.
- Active pause acknowledged in 19.281 ms and held without GPU work for 8.005 seconds.
  Four camera edits measured 114.893/123.272 ms median/95th percentile from edit to
  observed current-image publication, including observer polling.
- 119 native USD outputs, 38 GPU texture/environment cases, 14 PDF distributions,
  40 CPU image cases, native ingress probes and 12 HDRI/OpenPBR furnace configurations
  passed. Seven texture-vs-constant comparisons matched exactly.
- Existing sealed s5/s4 and 109-case material regressions passed. Vulkan validation
  stayed silent through teardown. Python checks passed on 3.12/3.14 and native H22.
- The portable bundle also passed package-only discovery from a relocated path
  with spaces and an actual relative-asset texture/HDRI render in Houdini 22.0.429.
  Its renderer, shaders and Python runtime bytes match the verified installation.

These results describe the recorded fixtures on Windows 11 / RTX 4090. They do not
establish general hardware compatibility or arbitrary OpenPBR/Karma appearance
parity. The release manifest binds included files, tested source hashes and receipt
hashes. Detailed raw logs/renders remain local; machine-specific install/rollback
records are intentionally absent from the public binary bundle.

## Known limits

Filtering uses level zero. UDIMs, image sequences, mipmaps, normal maps, arbitrary
shader graphs, additional OpenPBR lobes, material subsets, instancing and subdivision
remain unsupported. HDRIs illuminate and reflect; camera background is transparent.
External edits to the same image file require Off/On to reload it. Native asset
errors produce material fallback or dome exclusion; the stage support report
does not claim to open/decode files.

Limits: 16M texels per image, 32M scene texels, 128 images, 65536 bindings and eight
textured domes. Material inputs retain bounded ranges; HDRI radiance can exceed 1.
One initial GUI startup spent approximately 32 seconds initializing the backend;
its cause remains unresolved. An unchanged warm repeat published in 135.610 ms.
Earlier failed attempts remain preserved in development evidence.

The package is gated to Windows and exact Houdini build 22.0.429. This is a preview,
not a claim of feature completeness. Houdini and its SDK dependencies are required
and are not included. Apache-2.0, TOST-1.0, MIT and Adobe OpenPBR notices accompany
the bundle. HoudiniRT is independent of SideFX.
