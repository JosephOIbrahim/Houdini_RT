## Quick Install (Windows / Houdini 22)

1. Extract `KarmaRT-v2.0.0-Houdini22.zip` (or navigate to `extensions/karma_rt/`).
2. Run:
   ```powershell
   python tools/install_package.py --quarantine-legacy --xpu-turbo-env
   ```
3. Launch Houdini 22, switch to the **Solaris** desktop, and open **Karma RT** from the **Karma RT** shelf or **New Pane Tab Type → Karma RT**.
